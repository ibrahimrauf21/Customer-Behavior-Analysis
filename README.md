# 📊 Customer Behavior Analysis

An end-to-end data analytics project focused on understanding customer purchasing behavior, identifying trends, and generating actionable business insights using **Python, PostgreSQL, SQL, and Power BI**.

## 📌 Project Overview

This project analyzes customer shopping data to understand how factors such as demographics, purchase frequency, product categories, discounts, reviews, and spending behavior influence customer activity.

The project follows a complete analytics workflow:

**Data → Python → PostgreSQL → SQL → Power BI → Business Insights**

The goal was to transform raw customer data into an interactive dashboard that could help businesses better understand their customers and make data-driven decisions.

## 🛠️ Tools & Technologies

* **Python** — Data cleaning, preparation, and exploratory analysis
* **PostgreSQL** — Database storage and management
* **SQL** — Data analysis and business-focused queries
* **Power BI** — Interactive dashboards and data visualization
* **Jupyter Notebook** — Python-based analysis and documentation

## 🔄 Project Workflow

### 1. Data Preparation & Exploration — Python

The raw customer dataset was imported into Python and prepared for analysis.

Key tasks included:

* Inspecting the dataset and identifying data quality issues
* Cleaning and transforming columns
* Handling missing and inconsistent values
* Creating analysis-ready variables
* Exploring customer demographics and purchasing patterns

### 2. Database Management — PostgreSQL

The cleaned dataset was loaded into a PostgreSQL database to simulate a real-world analytics environment.

PostgreSQL was used to:

* Store the cleaned customer data
* Structure the dataset for analytical queries
* Create a centralized source for business analysis
* Practice working with relational databases

### 3. Business Analysis — SQL

SQL queries were developed to answer business questions and identify meaningful customer trends.

Analysis focused on areas such as:

* Customer purchasing behavior
* Product preferences
* Customer demographics
* Purchase frequency
* Spending patterns
* Discounts and promotional behavior
* Customer segmentation
* Factors associated with purchasing activity

### 4. Dashboard Development — Power BI

The analyzed data was connected to Power BI to create an interactive dashboard.

The dashboard provides visual insights into:

* Customer demographics
* Purchase behavior
* Product categories
* Spending patterns
* Customer segments
* Purchasing trends
* Key performance indicators

Users can interact with the dashboard using filters and visualizations to explore different customer groups and identify patterns.

## 📈 Key Business Questions

The analysis was designed to answer questions such as:

* Which customer segments generate the most purchasing activity?
* Which products or categories are most popular?
* How does purchase frequency vary between customers?
* What demographic characteristics are associated with different purchasing behaviors?
* How do discounts relate to customer purchases?
* Which customer groups should businesses prioritize?
* What trends could help improve customer engagement and sales?

The insights generated can help businesses:
